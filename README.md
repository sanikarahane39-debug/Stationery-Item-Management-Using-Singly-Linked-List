# Stationery-Item-Management-Using-Singly-Linked-List
Stationery Item Management Using Singly Linked List is a simple C++ project used to manage stationery items efficiently. Each item is stored as a node containing the item name, quantity, and a pointer to the next node. The system allows the user to insert, delete, search, and display stationery items using a Singly Linked List.
